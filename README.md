제목 : (갤럭시(One UI 7, 8), 보안 폴더가 정상적으로 실행되지 않습니다)

대응방법 :
최신 소프트웨어(One UI 7, 8)에서 보안 폴더 잠금 해제 후 정상적으로 진입되지 않는 현상이 발생할 수 있습니다.

아래 방법으로 개선을 안내합니다.

휴대전화를 재부팅한 후 보안 폴더를 다시 실행

최근 앱 화면(제스처)을 이용해 보안 폴더 앱을 완전히 종료 후 재실행

또한 보안 폴더 자동 잠금 설정이 ‘즉시 잠금’으로 되어 있는 경우,
다른 잠금 옵션으로 변경 후 사용을 안내합니다.

경로 :
설정 > 보안 및 개인정보 보호 > 기타 보안 설정 > 보안 폴더 > 자동 잠금
→ ‘즉시 잠금’ 외 다른 옵션 선택

해당 현상을 개선한 소프트웨어를 배포할 예정이므로 소프트웨어 업데이트를 통해 최신 상태 유지하도록 안내합니다.

제목 : (갤럭시, 삼성 헬스 앱에서 걸음 수 카드의 세부 설정 중 ‘표시할 걸음 수 데이터 선택’ 메뉴가 보이지 않습니다)

또한 일일 활동 카드의 걸음 수는 실시간 표시가 아닌 약 1분 단위로 동기화되어 업데이트됩니다.

※ 갤럭시 워치(Wear OS)를 휴대전화와 연동하여 사용하는 경우,
워치의 걸음 수 타일에서는 기존과 동일하게 실시간 걸음 수를 확인할 수 있습니다.
